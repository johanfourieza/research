# research

Replication data and reproducible files for research projects by
**Johan Fourie** (Stellenbosch University) and collaborators.

Projects are filed by year, one folder per paper: `<year>/<project>/`. Each
project folder is a self-contained data package with its own README,
codebook, license and loader script. Papers are posted at working-paper
stage.
